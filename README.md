> **Transforme dados brutos em decisões estratégicas em segundos.**

O **DataSight Pro** é uma ferramenta de análise de dados "No-Code" para o usuário final, construída inteiramente em Python. Ela permite que qualquer pessoa faça upload de planilhas complexas e receba instantaneamente um dashboard interativo com KPIs, tendências de crescimento e relatórios textuais automáticos.

---

## 🚀 Funcionalidades

* **Ingestão Universal:** Suporte nativo para arquivos `.csv` e `.xlsx`.
* **Mapeamento Inteligente:** O usuário define quais colunas representam Valor, Categoria e Data, permitindo analisar qualquer formato de planilha.
* **Motor de Análise Estatística:** Algoritmos em Python (Pandas) que calculam automaticamente:
    * Crescimento Mês a Mês (MoM).
    * Princípio de Pareto (Curva ABC de produtos).
    * Ticket Médio e Share de Receita.
* **Visualização Interativa:** Gráficos dinâmicos com **Plotly** (Zoom, Pan, Hover).
* **Dark Mode Nativo:** Interface moderna e profissional.
* **Gerador de Relatórios:** Botão para exportar um resumo executivo em `.txt` pronto para envio.
* **Privacidade Total:** Processamento 100% local ou em memória, sem envio de dados para APIs de terceiros.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Frontend/Framework:** Streamlit
* **Manipulação de Dados:** Pandas
* **Visualização:** Plotly Express & Graph Objects
* **Engine:** Algoritmos proprietários de análise descritiva
